# Pyomo Sensitivity Studio — proposed enterprise design direction

Use a desktop-first analytical application shell for operations-research practitioners. The visual language should feel precise, reliable, and calm: a neutral graphite/slate foundation, white working surfaces, restrained cobalt for primary actions, and semantic status colors. Avoid consumer gradients and decorative marketing imagery.

- Layout: persistent left navigation, top command bar, spacious desktop analysis canvas.
- Typography: Inter or equivalent modern grotesk for UI; a clear monospace face for model code and numeric results.
- Surfaces: subtle borders, small elevation, 8px spacing rhythm, 8–12px radii.
- Data: compact but legible tables, tabular numerals, right-aligned numbers, row dividers, sticky headers where helpful.
- States: distinguish ready, solving, optimal, warning, and failed status through icon-plus-label badges; never color alone.
- Accessibility: keyboard-visible focus states, 4.5:1 minimum text contrast, controls with labels, and responsive collapse of the sidebar.
